### 功能

- 📄 完整的 **GitHub Flavored Markdown**（GFM）支持
- 📝 从 **本地** / **远程仓库** 加载文件
- 📁 无缝 **集成本地资源**（引用的本地图片等）
- 🪶 **在线编辑** 和 **预览** Markdown 文件
- 🖨️ **打印质量** 的 Markdown 渲染
